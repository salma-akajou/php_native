# 📱 PHP Native Lab

## 📌 Description
Ce projet est un lab réalisé dans le cadre de l’apprentissage de **PHP Native** pour le développement d’applications mobiles Android.  
L’objectif est de comprendre le fonctionnement de base de PHP Native, depuis l’installation jusqu’à l’exécution d’une application simple.

---

## 🎯 Objectifs du lab
- Installer et configurer l’environnement PHP Native
- Lancer une application Android via émulateur
- Tester un projet simple (Hello World)
- Consommer une API externe
- Personnaliser l’interface de base(icône / Menu)

---

## 🛠️ Étapes réalisées

### 1️⃣ Installation de l’environnement
- Installation de PHP Native
- Configuration des dépendances (Java, Android Studio, Gradle…)
- Vérification du bon fonctionnement de l’environnement

### 2️⃣ Test Hello World
- Création d’une application simple
- Lancement sur l’émulateur Android
- Vérification de l’affichage du message "Hello World"

### 3️⃣ Consommation d’une API
- Implémentation d’un appel API
- Récupération des données
- Affichage des résultats dans l’application

### 4️⃣ Personnalisation de l’application
- Modification de l’icône et menu de l’application
- Test des changements sur l’émulateur

---

## ▶️ Lancer le projet

```bash
# Installer les dépendances
composer install

# Lancer l’application Android
php artisan native:run
